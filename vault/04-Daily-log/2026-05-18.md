## What I learned

- **GitHub Pages from a private repo needs GitHub Pro ($4/mo)** — free Pages requires a public repo
- Two-repo pattern (private source + public deploy) is the free workaround for source-private + page-public without Pro
- Claude Code marketplace is light on frontend tooling — better to just iterate with the CLI
- Sector-relative scoring is the standard way to avoid sector bias in composite rankings (see [[05-Learning/Sector-relative-scoring]])
- Prompt caching applies to reused system prompts even within a single run — small win, free hygiene
