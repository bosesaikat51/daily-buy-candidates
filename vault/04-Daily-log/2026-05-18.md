### What I learned

- `gh repo create --push` fails the push (but still creates the remote) if the gh token lacks `workflow` scope and the commit includes `.github/workflows/*.yml`. Fix: `gh auth refresh -s workflow`, then `git push`.
- Even with the gh token refreshed, `git push` was hitting 403 because git was using a cached fine-grained PAT from the credential manager. `gh auth setup-git` configures git to use gh's token for github.com — the cleaner fix than editing the PAT scopes.
- Piping the secret value through stdin (`'value' | gh secret set NAME`) avoids putting the value in the visible argv.
- `winget install` writes the new install to system PATH but the *running* shell session doesn't pick it up until restarted — full path or `$env:Path` patch works for the current session.

### What I learned

(All distilled into [[05-Learning/yfinance]] under "Confirmed in Phase 1 smoke test")

- Wikipedia 403's the default urllib UA — `requests` with a real User-Agent fixes it
- Wikipedia STOXX 600 tickers are bare; need country → exchange suffix map for yfinance
- UK stocks price in **GBp (pence)**, not GBP — `VOD.L = 112.20` means £1.122
- `dividend_yield` is in **percent** (0.36 = 0.36%); `return_3m` is a **fraction** (0.14 = 14%) — never mix
- yfinance sector ≠ Wikipedia sector — use yfinance's Morningstar sector for grouping in score.py
- ETFs return mostly None for fundamentals — handle gracefully, they end up ranked on momentum + yield only
